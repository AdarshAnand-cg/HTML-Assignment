## 🎬 Animation Showcase

One of the major focuses of this repository is **web animation**.

The projects include different types of animations such as:

### 🔄 Loading Animations

Animated loaders created using CSS:

```css
.loader {
    width: 50px;
    height: 50px;
    border: 5px solid #ddd;
    border-top: 5px solid #3498db;
    border-radius: 50%;
    animation: spin 1s linear infinite;
}

@keyframes spin {
    from {
        transform: rotate(0deg);
    }

    to {
        transform: rotate(360deg);
    }
}
```

### 🖱️ Hover Animations

Interactive effects that respond when the user moves the mouse over an element.

### 🎯 Transform Animations

Examples include:

* `translate()`
* `scale()`
* `rotate()`
* `skew()`

### 🌈 Keyframe Animations

Complex animations created using CSS `@keyframes`.

### 💡 Button Animations

Modern buttons with:

* Hover effects
* Smooth transitions
* Scale effects
* Color transitions
* Shadow effects
